# Madrid HHH Wine Run

Single-page event site for the Madrid Hash House Harriers Wine Run.

## Event
- Sunday 11 October 2026
- 13:00 start
- Meet at Lago Metro station, Madrid
- €20 per person
- 9 wines
- 10 km Machos route
- 5 km Wimps / walkers route
- Pay on the day
- Limited spaces

## Site
The entire site is in `index.html` and has no framework or build dependency.

Expected GitHub Pages URL once Pages is enabled:
https://thearchcobh.github.io/HHH/

## One-time GitHub Pages setup
Repository → Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / root.
